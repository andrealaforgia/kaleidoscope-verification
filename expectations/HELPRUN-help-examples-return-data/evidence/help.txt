Kaleidoscope query API — usage

Examples (replace host/port, tenant bearer, and arguments as needed):

# Metrics: range query over a service window
curl 'http://localhost:9090/api/v1/query_range?query=process_cpu_utilization&start=2026-06-14T00:00:00Z&end=2026-06-14T01:00:00Z&step=15s'

# Logs over a service window
curl 'http://localhost:9090/api/v1/logs?service=checkout&start=2026-06-14T00:00:00Z&end=2026-06-14T01:00:00Z'

# Traces over a service window
curl 'http://localhost:9090/api/v1/traces?service=checkout&start=2026-06-14T00:00:00Z&end=2026-06-14T01:00:00Z'

# A single trace by id
curl 'http://localhost:9090/api/v1/traces/by_id?trace_id=4bf92f3577b34da6a3ce929d0e0e4736'

Accepted time format: RFC3339 (2026-06-14T00:00:00Z) or unix seconds (1718323200).
